# Screenshots Plan

Capture screenshots with demo data only. Do not include real customers, transcripts, API keys, local database content, benchmark spreadsheets, or screenshots from real meetings.

## Capture List

| Status | File | What It Captures | Why It Matters |
| --- | --- | --- | --- |
| Captured | `desktop-queue.png` | Desktop assistant queue with demo screenshot/transcript context | Shows the in-meeting copilot surface |
| Captured | `desktop-coach.png` | Live coaching output with readiness and next question | Shows the core AI value |
| Captured | `desktop-coach-alert.png` | Correction or out-of-catalog alert | Shows safety guardrails |

| Captured | `customers.png` | Customer list | Shows CRM-style context |
| Captured | `customer-profile.png` | Customer profile and relationship memory | Shows personalization and memory |
| Captured | `documents.png` | Document upload/list page | Shows RAG knowledge management |
| Captured | `settings.png` | Organization or model settings | Shows configurability |

## Capture Rules

- Use fictional customers and organizations.
- Avoid real screenshots from client calls.
- Hide tokens, local DB paths, and API keys.
- Crop or blur any personally identifiable information.
- Prefer dashboard/demo data over production-like records.
