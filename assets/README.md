# Assets

This folder is reserved for safe portfolio assets such as exported diagrams, sanitized screenshots, and presentation graphics.

## Allowed Assets

- Exported Mermaid diagrams.
- Demo-only screenshots.
- Portfolio cover graphics.
- Sanitized product mockups.

## Disallowed Assets

- `.env` files or credentials.
- Local databases.
- Real customer records or transcripts.
- Benchmark spreadsheets with private notes.
- Runtime screenshots from real meetings.
- Raw source code copied from the implementation repository.
