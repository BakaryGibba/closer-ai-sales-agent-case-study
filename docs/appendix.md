# Appendix

## Glossary

| Term | Meaning |
| --- | --- |
| Electron | Desktop framework combining Chromium and Node.js |
| IPC | Inter-process communication between Electron renderer and main process |
| RAG | Retrieval-Augmented Generation, grounding model output in retrieved documents |
| Qdrant | Vector database used for semantic document search |
| Ollama | Local model runtime used for privacy-friendly LLMs and embeddings |
| Readiness | Coaching state such as discovery, clarifying, or ready to recommend |
| Tenant | Organization or customer account with its own configuration and data |

## Safety Notes

This case study should not include:

- `.env` files or API keys.
- Local databases.
- Real customer records.
- Meeting transcripts.
- Screenshot captures from real calls.
- Benchmark spreadsheets with private evaluation notes.
- Raw source code dumps.
